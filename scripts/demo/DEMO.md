
## 電話AIデモ台本(024 — 商談用・所要5分)

前提: stg 稼働中 / デモ番号(現在 +1 470-466-1632、050到着後は差替)/ 受け手は
`https://raku-rag-stg.my.connect.aws/ccp-v2` に管理者でログインし Available にしておく。

1. **発信** → 挨拶が流れる
2. 「**圧力容器V-205の耐圧試験の保持時間を教えてください**」→ 根拠付き回答+
   「作業実施前に現場責任者または有資格者の確認が必要です」(安全免責を必ず聞かせる)
3. 続けて「**コンベアのM8ボルトの締付トルクは?**」→ 連続質問が通ることを見せる
4. 「**人につないでください**」→ 転送アナウンス → CCP で受話(要約・マスク済み経緯・引用が
   引き継がれることを画面共有で見せる)
5. 通話終了後、Web の **/phone → 通話履歴タブ** → いまの通話を開く(マスク済み全文文字起こし)
6. その場で **QAレビュー**を記録(ナレッジ不足トピックを入力)→ **改善キュー**に載る → **KPIタブ**
   (応答率・AI完結率・ナレッジギャップ)まで一気に辿る
7. 締め: 品質・KPI画面の**監査エビデンスパック**を生成 —「この通話も監査チェーンに入っており、
   改ざん検証付きで月次帳票にできる」で終える

要点トーク: 「答えるAI」ではなく「答えてはいけない時を知っていて、それを証明できるAI」。
