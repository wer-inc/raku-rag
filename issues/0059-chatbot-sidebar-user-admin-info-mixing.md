# 0059 — ChatBot右側パネルで利用者向け情報と運用KPIが混在する(系統 = chatbot / UX)

> Priority: **P1/High** / Status: **Resolved (verified 2026-07-02)** / Labels: `chatbot`, `ux`, `admin-info`, `demo-readiness`

## 解決の検証(2026-07-02, Sprint2 S2-2)

現行 `FullSaasScreen.tsx` で DoD を突き合わせて確認済み:

- ✅ 一般ユーザーのデフォルト表示に `会話数` / `確認依頼率` / `session` / `state` は出ない —
  すべて `showOpsInfo`(= `canViewChatbotOps`: admin/tenant_admin/platform_admin/ops_owner のみ)
  ゲート内、かつ折りたたみ `<details>「運用情報」` の中に隔離。
- ✅ 利用者パネルは安心情報のみ: 利用状態 /「参照範囲」/ ナレッジ件数 /「承認済みデータのみ使用」/
  確認依頼状態(`chatbot-conversation-status` セクション)。
- ✅ `外部接続へ` の導線は chatbot 画面から撤去済み。
- △ 参照範囲セレクタは右パネルではなく **入力フォームのメタ行** に残置(参照範囲が単一なら実質固定)。
  DoD の字義(パネル非表示)は満たすが、複数参照範囲の一般ユーザーには選択肢が見える。これは
  仕様判断としてこのまま採用(質問前に範囲を意識できる方が安全)。
- モバイル幅の重なりは未計測(残タスクとして #0060 系のポリッシュに委譲)。

## 背景(なぜ今)

stg の `/chatbot` 右側パネルに、参照範囲、会話状態、会話数、引き継ぎ率、診断情報が同時に表示されていた。
ユーザーから「それらは何のためにあるか」「改善して」と確認があり、通常ユーザー向けの安心情報と
管理者/開発者向けの運用情報が混ざっていることが分かった。

## どんな課題か

- 期待挙動: 通常ユーザーには「どのデータを参照しているか」「今質問できるか」「承認済み根拠だけを
  使うか」がすぐ分かる。
- 実際の挙動: `会話数`, `引き継ぎ率`, `session`, `state` などの内部/運用情報が同じ階層に見える。
- `引き継ぎ率 24%` は営業デモでは「失敗率」に見えやすく、顧客の信頼を下げる。
- ナレッジ追加済みの状態で chatbot を使う前提では、`外部接続へ` のようなセットアップ導線も
  通常の会話画面ではノイズになる。
- 参照範囲の詳細設定も、必要になった時に専用の設定画面として戻す方がよく、通常の会話画面には
  置かない。

## どこで起きたか

- 画面: `/chatbot`
- API: なし(UI表示の情報設計)
- コード: `apps/web/app/components/FullSaasScreen.tsx`, `apps/web/app/globals.css`
- 環境: AWS stg
- run id / ingestion id / correlation id: なし(ユーザー手動確認)
- 再現条件: `/chatbot` を表示し、右側パネルを見る。

## 影響

- 営業デモへの影響: 管理者KPIが一般ユーザー向けの状態表示に見え、Bot品質が悪く見える。
- 本番クライアントへの影響: 現場ユーザーが「質問できるか」より内部状態に気を取られる。
- セキュリティ、監査、データ品質、UX への影響: session/state は秘密ではないが、診断情報は標準表示
  ではなく管理者向けに閉じるべき。

## どう解決すべきか

1. 右側パネルを `参照範囲設定`, `この会話`, `運用情報` に分離する。
2. 通常表示では `利用状態`, `参照範囲`, `同期済みデータ件数`, `承認済みデータのみ使用`,
   `人間への相談` を見せる。
3. `会話数`, `引き継ぎ率`, `session`, `state` は管理者向けの折りたたみ内に移す。
4. `担当者引き継ぎ中` は出しっぱなしにせず、ユーザーには「担当者に引き継ぎ済み」または
   「必要時に相談できます」と表現する。
5. `外部接続へ` や参照範囲有効化ボタンなどのセットアップ導線は chatbot の主画面から外す。
6. 右側パネルの参照範囲設定セクションも外し、会話状態だけを残す。
7. UI smoke で右側パネルの通常表示を確認する。

## 受け入れ条件(DoD)

- 一般ユーザーのデフォルト表示に `会話数`, `引き継ぎ率`, `session`, `state` が出ない。
- 管理者は折りたたみ内で運用情報を確認できる。
- 参照範囲が有効なら、右側パネル上で「質問できます」が明確に見える。
- chatbot 画面に `外部接続へ` が表示されない。
- 右側パネルに `参照範囲設定` や参照範囲選択リストが表示されない。
- モバイル幅でもテキストが重ならない。

## スコープ外

- 管理者KPI画面の再設計。
- source exposure policy / ACL / approved evidence の挙動変更。
